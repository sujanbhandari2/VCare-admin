# Firebase Setup by Flavor

This project uses per-flavor Firebase configuration files. Android and iOS must use bundle IDs that match the app flavors.

## Required bundle IDs

| Flavor | Android application ID | iOS bundle ID |
|--------|------------------------|---------------|
| dev | `com.vcare.admin.dev` | `com.vcare.admin.dev` |
| qa | `com.vcare.admin.qa` | `com.vcare.admin.qa` |
| uat | `com.vcare.admin.uat` | `com.vcare.admin.uat` |
| prod | `com.vcare.admin` | `com.vcare.admin` |

## File locations

| Platform | Per-flavor source files | Active copy used at build time |
|----------|-------------------------|--------------------------------|
| Android | `android/app/google-services-{flavor}.json` | `android/app/google-services.json` |
| iOS | `ios/Runner/GoogleService-Info-{flavor}.plist` | `ios/Runner/GoogleService-Info.plist` |
| Dart | Generated by script | `lib/firebase_options.dart` |

## Configure a flavor locally

```bash
./scripts/configure_flavor.sh dev
```

This command:

1. Copies `.env.dev` to `.env`
2. Runs `./scripts/setup_firebase_config.sh dev`
3. Runs `flutter pub get`

## Firebase Console checklist

For each flavor, register the iOS and Android apps in the Firebase project with the bundle IDs above, then download and replace:

1. `android/app/google-services-dev.json`
2. `android/app/google-services-qa.json`
3. `android/app/google-services-uat.json`
4. `android/app/google-services-prod.json`
5. `ios/Runner/GoogleService-Info-dev.plist`
6. `ios/Runner/GoogleService-Info-qa.plist`
7. `ios/Runner/GoogleService-Info-uat.plist`
8. `ios/Runner/GoogleService-Info-prod.plist`

After replacing files, run:

```bash
./scripts/configure_flavor.sh <flavor>
```

## Verify Android package mapping

The Firebase setup script selects the Android client entry whose `package_name` matches the flavor. If the expected package is missing from a `google-services-*.json` file, the script falls back to the first client and prints a warning.

## Notes

- Never commit secrets from production `.env` files.
- iOS `GOOGLE_APP_ID` values must come from Firebase Console for the registered iOS apps under `com.vcare.admin.*`.
- Until iOS apps are registered in Firebase Console, push notifications and other Firebase iOS services may not work even after bundle ID alignment.
